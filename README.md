# Пример моей верстки сайта 

## Описание
Небольшой сайт с версткой.

## Технологии
- **Язык/Фреймворк:** `TypeScript`, `React`, `Next`
- **Библиотеки:** `Tailwind CSS`
- **Инструменты разработки:** `Bun`

## Установка
1. Клонируйте репозиторий:
    ```bash
    git clone https://github.com/ваш-пользователь/название-проекта.git
    ```
2. Перейдите в папку проекта:
    ```bash
    cd название-проекта
    ```
3. Установите зависимости:
    ```bash
    npm install
    ```
    или, если вы используете Bun:
    ```bash
    bun install
    ```

## Запуск
Для запуска проекта в режиме разработки выполните:
```bash
npm run dev
